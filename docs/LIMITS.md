# Limits

This page collects the limits, budgets and caps of Midnight Explorer in one place: how
many windows of a kind may be open, how large a file a viewer or comparison takes, how
many items one operation accepts, how much memory a helper process may use, and similar
bounds. A limit here is a fixed number in the code that a user can reach, or that
decides how the application behaves under load. Per-call buffer sizes without an
observable effect are left out; the feature documents linked in each row describe the
surrounding behaviour.

Every value was read from the source code of this commit, not copied from other
documents. Rows marked *(internal)* bound memory, queues or work inside the application
and are not normally visible; all other rows can be reached by a user. Sizes use binary
units: 1 KiB is 1,024 bytes, 1 MiB is 1,048,576 bytes and 1 GiB is 1,073,741,824 bytes.
"Where" names the source file (relative to the repository root) and the constant or
function that holds the value.
