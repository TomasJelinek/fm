# Inline Tree Copy Implementation Plan

> Use `superpowers:subagent-driven-development`; backend and frontend ownership
> are separate, with one Windows Cargo build lease.

**Goal:** F5 copies actual selected native/archive tree occurrences through the
normal verified queue and progressively clears successful selections.

**Architecture:** The tree actor captures an immutable opaque source batch before
the dialog. Confirmation submits it through existing copy preparation/admission.
Typed occurrence completions feed the ordered tree selection actor.

**Tech stack:** Existing Rust/Tokio/Slint services; no dependency or ABI changes.

**Spec:** [Tree copy](../specs/2026-11-10-tree-copy-design.md).

## Global constraints

Preserve unrelated dirty work, raw Unicode/provider identities, backend-only I/O,
platform separation, rustfmt 100 columns, source files at most 100000 bytes.
Generated evidence belongs under `_build/qa/tree-copy`; reuse existing targets.
No commits or deployment until integrated review/verification; do not mark the
overall application goal complete for this slice.
