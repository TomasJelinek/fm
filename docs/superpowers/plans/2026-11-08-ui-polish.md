# Panel and dialog polish

Approved scope: the user's November 8 UI follow-up and filter clarification.

1. Keep shared action toolbar; return View and Sort to each panel's drive bar.
   Popups bind the originating panel and directory, including delayed touch input.
2. Filter dialog uses OK/Cancel and Show all. No enable checkbox. A dismiss
   control on the panel filter indicator disables the filter immediately while
   retaining its expression. Stale validation cannot restore a cleared filter.
3. Parent navigation publishes the returned child focus and viewport with the
   displayed directory; test the first rendered frame, not eventual animation.
4. Archive custom extensions use a compact add affordance and removable entries.
   Existing built-in extension checkboxes and transactional settings remain.
5. Review dialogs for unnecessary actions, oversized input controls and clipping.
   Keep consistent footers, scrolling bodies, cancellation and keyboard access.
6. Improve authored SVG action icons with restrained accents and theme-safe
   contrast; preserve native icons and the approved compressed-archive artwork.
7. Run focused behavior/layout tests, a debug build and real startup check.
   Update design and verification notes with actual evidence and remaining limits.

Modern pattern references (consulted November 8, 2026):

- [Fluent 2 toolbars](https://fluent2.microsoft.design/components/web/react/core/toolbar/usage/):
  logical groups, brief tooltips, accessible labels and overflow.
- [Fluent 2 tags](https://fluent2.microsoft.design/components/web/react/core/tag/usage):
  removable user-entered values and wrapping.
- [Fluent 2 dialogs](https://fluent2.microsoft.design/components/web/react/core/dialog/usage):
  focused actions and reduced redundancy.
- [Fluent 2 iconography](https://fluent2.microsoft.design/iconography):
  recognizable, functional icons sized for their context.
