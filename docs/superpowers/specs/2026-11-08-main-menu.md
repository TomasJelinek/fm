# Discoverable F10 main menu

F10 exposes existing important actions in five groups: Files, Selection, Panels
and navigation, Tools, and Application. The default view shows every group;
a category picker narrows the list. The list scrolls within the available window,
including 320×200. Every action has a label, icon and its current effective configured key.
The menu reads the same compiled shortcut map as input routing, including user
overrides and default-key suppression. A removed binding leaves the key column
empty. An assigned plain function key is preferred in that column; the tooltip
shows all aliases. Changes and restored defaults refresh an already open menu.
Options Cancel restores both routing and displayed hints.
Escape, the close button and clicking outside dismiss without invoking an action.

Use the existing semantic action dispatcher and confirmation/preparation paths.
The menu and function bar share their availability predicate; parent `..` rows
cannot become mutation targets, and unsupported native/network operations remain
visible but disabled. Backend guards remain authoritative. Menu-only window/view
commands are added to the shortcut catalogue with no mandatory default key so
they can also be configured in Options. No new filesystem operation is introduced.

Keep stable action identities while icons, shortcuts or availability change.
Closing the menu precedes dispatch into another dialog. Existing keyboard focus
and active-panel routing apply. The reference is Salamander's grouped menus and
key hints in `src/lang/lang.rc2`; source code is not copied.

Verification covers real F10 input, important command visibility, active-pane
dispatch, disabled parent/archive/network actions, remapped hints, keyboard and
pointer dismissal, category selection and narrow-window access to the final row.
