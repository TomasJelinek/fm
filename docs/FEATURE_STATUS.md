# Feature status for 0.1.0

This is an early preview. A design document is not evidence that a feature is available.

| Feature | Current implementation | Remaining work / design |
| --- | --- | --- |
| Native panels | Windows and Linux browsing, tabs/bookmarks, multiselection, locale sorting, watches, selection-aware directory sizes, three view modes, themes and configurable shortcuts | macOS adapter remains pending |
| Panel status | Filename or selection summary takes space before secondary metadata; Windows attributes use compact characters such as A/C/R with a tooltip legend; clicks copy full captured values | Unix symbolic/octal permissions remain. Narrow panels elide only after assigning the available width to the name. [Verification](verification/2026-11-07-status-and-viewer-readability.md) |
| Compact main window | Exact 320×200 logical minimum at every density; active pane and other-pane rail, command editor and horizontally scrollable function keys; Options/Jobs stay visible | Regular two-pane controls return when space permits. See [small-window verification](verification/small-window.md) |
| Window placement | Saved physical normal bounds, maximized/fullscreen state and monitor; unavailable monitors fall back to the primary work area; viewer windows inherit parent bounds and always accept Escape | Wayland owns absolute placement. See [window geometry](verification/window-geometry.md) |
| Dialogs | Movable headers, bounded position, compact scrolling, original attributes/time icon and simplified metadata editor | Backend validation/confirmation remain required before applying changes |
| Shared Windows build startup | Matching protected deployment can supply viewers, thumbnails and archive providers to the original build EXE; normal Windows build helper deploys/registers it | Raw Cargo builds need explicit registration; restart after deployment. [Runtime discovery](developer/RUNTIME_DISCOVERY.md) preserves package/ancestor trust checks |
| Keyboard settings | Search, capture, conflicts and reassignment; fixed first-character crash caused by retiring hovered tooltip rows during Slint popup handling | Causal native release reproduction and corrected four-profile matrix passed 657 assertions. [Verification](verification/2026-11-07-keyboard-search-crash.md) |
| Drag selection | Rectangle selection from empty panel space in Details/Brief/Thumbnails; Ctrl/Shift, archive identities, edge scrolling and revision-checked backend ranges | Windows software input regressions pass; final Linux/native release qualification remains. Dragging actual rows retains native file drag/drop. [Selection contract](developer/SELECTION.md) |
| Media thumbnails | Installed independent image/video workers, private persistent cache, bounded background decoding and progressive animation of visible selected videos; Options → Previews controls enablement and cache clearing | Requires trusted installed helpers. Images: PNG/JPEG/GIF/WebP/BMP/ICO/TIFF. Initial video codec/container set is limited; no MP4/H.264 promise. Network/unclassified storage requires opt-in; archive-member previews remain pending. See [worker SDK](developer/WORKER_SDK.md) |
| Panel search/filter | Filename prefix search, optional quick-search filtering, and per-panel Masks/Regex/typed metadata Expression filters on Ctrl+F12; backend validation preserves the last valid filter | Expressions evaluate listing snapshots, including folders; missing fields remain unknown. Archive name encoding can be unavailable. Inline-tree ancestor context waits for TREE-01. [Syntax, limits and semantics](developer/METADATA_FILTERS.md); [verification](verification/2026-11-07-metadata-expression-filters.md) |
| Filename colors | Ordered masks/regex rules, source/executable/image/video/document presets, one base foreground and optional background; automatically derived focus/selection colors, four-state preview, nine themes including Carbon Green | Matching runs on backend snapshots; invalid drafts do not replace active rules; explicitly removing all presets survives restart |
| Internal viewers and F4 | Independent basic text/binary, source highlighting, Markdown, image and PDF packages; text wrap/search/copy, image/PDF Fit/1:1/zoom/pan, captured-order Space navigation; configurable external editor | Requires installed, enabled viewer packages in a trusted installation. Text selection/copy is bounded to the loaded page. Images decode at most 128 MiB of pixels and present at most 4 megapixels; animated formats show the first frame. See [viewer controls and limits](verification/2026-11-07-viewer-controls.md) and [image API](developer/IMAGE_VIEWER_API.md) |
| Copy | F5, clipboard and drag/drop share a bounded queue, independent SHA-256 readback, explicit folder merge and recoverable file replacement with retained originals; opt-in exact modified time for up to 64 native regular files | Provider capabilities govern replacement; strong identity-conditional overwrite is unavailable. Links/complete metadata preservation remain pending. [Transfer contract](developer/TRANSFERS.md) |
| Move | F6 and Cut/Paste copy, independently verify and remove each supported Windows source before copying the next file; optional exact modified time, up to 64 regular files | Qualified local fixed NTFS only; readonly files, hardlinks and alternate streams are refused. Late failure retains recovery; completed earlier moves remain. Linux refuses before publication until enforceable writer exclusion is available. Directory/link/virtual moves remain pending. [Transfer contract](developer/TRANSFERS.md) |
| Find files | Alt+F7 or the panel magnifier opens a native modeless window: multiple roots, masks, recursion, UTF-8 content, streamed results, Stop and validated Go to file | Windows/Linux native folders; explicit link/mount/encoding/budget exclusions. Archive search and guarded Open/Edit actions remain pending. [Find contract](developer/FIND.md) |
| Native mutations | Rename, empty-file creation, recursive F7, confirmed Trash/permanent deletion, attributes/timestamps/case changes | Capability limits and per-item failures remain explicit |
| Directory comparison | Ctrl+F10 comparison is implemented | Not a replacement for a recursive synchronization tool |
| Checksums | Ctrl+F8 opens a modeless captured-selection window; SHA-256 default, SHA-512/MD5/SHA-1, streamed progress, Stop, per-hash/full-row copy and verified manifest export | Backend and Windows software-window tests pass; final integrated/native release qualification remains. Manifest import is later scope. [Checksum contract](developer/CHECKSUMS.md) |
| Archive providers | Installed independent workers browse ZIP/7z/GZIP/TAR and TAR.GZ/TAR.XZ/TAR.BZ2/TAR.ZST plus raw compressed streams; F5 copies out through the verified background queue | Bounded mounts: 64 MiB source/member and 128 MiB decoded budget. No writing into archives, passwords, nested mounts, RAR or external member launch. Missing/changed providers retain unavailable saved tabs. See [filesystem API](developer/FILESYSTEM_API.md) |
| PDF | Independent isolated PDF plugin with page controls, zoom and pan; Ctrl+PageUp/Down changes pages | Hayro rendering; unsupported/encrypted documents report an error. No scripts/network/link activation; bounded source/pages/rendering. See [PDF verification](verification/pdf-viewer.md) |
| File comparison | Ctrl+Shift+C opens text differences or image comparison with Side-by-Side, Swipe and Onion Skin | Native regular files only; two active-panel selections or one selected/focused file per panel; bounded text diff and raster sizes |
| Custom Commands | Windows/Linux backend supports captured native arguments/cwd, per-item or grouped execution, previews and bounded process ownership; settings includes drag ordering, a conditional toolbar and configurable shortcuts | Windows Program/PowerShell and Linux Program/POSIX profiles; Cmd custom scripts and native macOS support remain unavailable. [Custom Commands design](superpowers/specs/2026-11-07-user-commands-design.md), [settings verification](verification/2026-11-07-custom-command-settings.md) |
| Native and network providers | Native mounted filesystems/paths work through built-in OS adapters | Network discovery plugins, native-provider plugin migration and inline directory branches remain pending |

The [follow-up stages](superpowers/plans/2026-11-05-follow-up-stages.md) preserve
the uncompleted requests. Native copy currently runs serially with a 256 KiB
buffer. Future concurrent copying is permitted only when both source and
destination are positively classified as local SSD storage. HDD, network and
unknown storage retain serial copying. Details are in the repository's security
and architecture documents.

The release archives include this status file; relative design links are intended
for the repository version at https://github.com/TomasJelinek/fm.
