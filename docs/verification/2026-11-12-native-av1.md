# Native AV1 helper qualification — 2026-11-12

The pinned dav1d 1.5.4 Linux helper builds and installs a release static library on
WSL Ubuntu 24.04 x86-64. A real C program links against that archive through its
installed pkg-config metadata and passes decoder initialization, empty-input,
flush and close checks. This is native build/link/lifecycle evidence, **not an
AVIF decode, pixel correctness, restricted-worker or distribution qualification**.
No AVIF feature, worker manifest, Cargo lockfile or vendor patch was changed for
this qualification.

## Helper and real linkage

The production `plugins/image-decoder/native/build-linux.sh` completed all 100
native build steps and installed under
`_build/image-formats/native-linux/prefix-linux-x86_64/`. Configuration keeps
assembly enabled, `buildtype=release`, `default_library=static`,
`wrap_mode=nodownload`, and tools/tests/examples/docs disabled. The source archive
is reused offline and revalidated by the production preparation helper.

The resulting `lib/libdav1d.a` SHA-256 is
`BCB16AE4F74078818D81A4C884A8A2815048F362B9F17E57991E9F0B21A80964`.
The real pkg-config flags contain `-ldav1d -pthread -ldl` on this host. The helper's
comment now accurately says “private system dependencies”. The initial helper
qualification changed only that comment; the later bootstrap integration below
adds isolated Meson startup. `PKG_CONFIG_SYSROOT_DIR` is unset so this prefix is not rewritten
through the unrelated private GUI dependency sysroot.

`static-link-probe.c` is compiled with `-Wall -Wextra -Werror` and the actual
`pkgconf --static --cflags --libs dav1d` output. It confirms version 1.5.4/API
`0x070000`, creates a decoder configured for two threads and a 16,384-pixel limit,
receives the expected `EAGAIN` without input, flushes, closes and checks that the
context pointer is cleared. Exit status is zero. Its linker map names the static
archive and `ldd` lists only libc and the loader, with no `libdav1d.so` dependency.
The probe SHA-256 is
`96FA30DE5BC167003556C588413E3AC051B1BF0DF3DB7A0F1152C1B142DB59C2`.

A second offline invocation takes the existing-build reconfigure branch and
succeeds with the same library hash. The archive's upstream `vcs_tag` step emits
“not a git repository” while checking the absent release-archive `.git` directory;
Meson keeps the intended version fallback `DAV1D_VERSION "1.5.4"`. The diagnostic
is preserved in the raw log; it does not fail the build or change the archive.
The final exported values are `SYSTEM_DEPS_DAV1D_LINK=static` and
`SYSTEM_DEPS_DAV1D_BUILD_INTERNAL=never`, with the installed prefix's pkg-config
directory in `PKG_CONFIG_PATH`.

The three existing native source-preparation tests also pass on Linux in 0.095 s:
corrupt cached bytes are rejected before extraction, an offline missing archive
is not fetched, and an output outside `_build` is rejected before creation.
No new test replaces these guards.


`dav1d-build.log`, `dav1d-reconfigure.log`, `static-link-probe.log`,

not decode compressed image data or establish those properties.
