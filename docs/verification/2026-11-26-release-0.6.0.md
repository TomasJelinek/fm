# Release 0.6.0 and its acceptance runs

Recorded on 26 November 2026. The [0.6.0 preview](../releases/0.6.0.md) was built,
tested and published from `2c3fd113` (tag `v0.6.0`): themes that follow the system's
appearance with Blue as the default dark theme, Harvest Navigator as the default
application icon in place of the Moon, a Browse button for Copy and Move destinations, the
View menu in shortcut order, the Linux GVfs drive list, release builds without debug
symbols and the other changes its notes list. Main moved on afterwards with the video
viewer's volume and mute (`cc4070da`), faster small-file copies (`9ba60210`, `49492f08`)
and command icon cleanup (`d11c868e`), which are not part of it.

## Builds and packages

- Windows: the release build of `2c3fd113` in a clean detached checkout (moved there from
  `078cf570`, the first build commit), Windows 11 x64, with the FFmpeg 9.0.2 libraries built
  from the official archive with the pinned SHA-256; the release ZIP
  `midnight-explorer-0.6.0-x86_64-pc-windows-msvc.zip` (245,891,753 bytes, SHA-256
  `1daf874dc7ee07c9956d2fa5a153e9b4166141773b5600b3c92a53b40f222a45`).
- Linux: the release build and package of `2c3fd113` in a WSL 2 Ubuntu 24.04 clone,
  `midnight-explorer-0.6.0-x86_64-unknown-linux-gnu.tar.gz` (207,429,382 bytes, SHA-256
  `bef9b9c5fc2c069147e5e7f1df12a9778a4015e264aedda9930f8b5f49957510`). Without debug
  symbols it unpacks to 468 MB, against 1,682 MB for 0.5.4.
- Both archives carry `LICENSE.txt` (Windows) or `LICENSE` (Linux) and a `README.txt`
  that begins "Midnight Explorer 0.6.0"; each `BUILD-INFO.json` names `2c3fd113`.
- Before publishing, the unpacked archives' `midnight-explorer` and
  `midnight-elevated-listing` executables were byte-identical to the tested release
  builds on both systems; the ZIP held no PDB, ILK or object files; its `thumbnailers`
  files named no grant for the workers' AppContainer; and the ignored extracted-installation
  tests (`midnight-thumbnail-host` integration `extracted_installation`,
  `midnight-media-host` `extracted_installation`) passed from a copy of that folder in a
  private profile installation.
- `SHA256SUMS` was signed by the owner with the release key; `release-signing.py
  verify --version 0.6.0` accepted it, and the four assets downloaded back from the
  published release matched `SHA256SUMS`, verified again, and the downloaded
  `SHA256SUMS.minisig` was byte-identical to the signed one.
