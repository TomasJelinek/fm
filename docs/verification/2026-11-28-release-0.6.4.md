# Release 0.6.4 and its acceptance runs

Recorded on 28 November 2026. The [0.6.4 preview](../releases/0.6.4.md) was built, tested
and published from `921a400b` (tag `v0.6.4`): one authorization for a folder and its
subfolders, selection keys that include folders, reads, copies, Find and folder sizes on
FAT32, exFAT, CD/DVD and file-ID-less network volumes, an MSI that refuses a second
installation scope, Windows binaries with a static C runtime, and lowercase document names.

## Builds and packages

- Windows: the release build of `921a400b` in a clean detached checkout, Windows 11 x64,
  with the C runtime linked statically (`+crt-static`) in the application and every plugin,
  the FFmpeg 9.0.2 libraries built from the official archive with the pinned SHA-256, and
  the explorer built after the authorization helper so that it records the helper's digest.
  The release ZIP `midnight-explorer-0.6.4-x86_64-pc-windows-msvc.zip` (247,869,474 bytes,
  SHA-256 `88bdacff36f346f56c1e26a03a1a68faaef704201c6893595f9368aabe0f50be`).
- Windows installer: `midnight-explorer-0.6.4-x86_64-pc-windows-msvc.msi` (194,912,256
  bytes, SHA-256 `74559a7cbd2b184be4d08827d3f20892ebd1e7815ab1b7ac99e32c8787173e01`),
  built from that ZIP; its verification compared all 2,372 packed files with the ZIP.
- Linux: the release build of `921a400b` in a WSL 2 Ubuntu 24.04 clone,
  `midnight-explorer-0.6.4-x86_64-unknown-linux-gnu.tar.gz` (208,218,647 bytes, SHA-256
  `158df35edad854b7aa9fbc0fb5de3b7794a1e8488202adddb22accc41d4d8b6f`); its
  `midnight-explorer` is byte-identical to the build that ran the Linux acceptance suite.
- Both archives carry `LICENSE.txt` (Windows) or `LICENSE` (Linux) and a `README.txt` that
  begins "Midnight Explorer 0.6.4"; each `BUILD-INFO.json` names `921a400b`.
- Before publishing: the ZIP's `midnight-explorer` and `midnight-elevated-listing` were
  byte-identical to the tested build; none of the ZIP's 27 PE files imports a Visual C++
  runtime DLL or the UCRT (none of the 163 in the build output either); the ZIP held no
  PDB, ILK or object files; all 198 Markdown files in the ZIP and 197 in the tar.gz have
  lowercase names; the unpacked ZIP's filesystem smoke test exited 0; and
  `package-release.py check-authorization-helper` passed.
- `SHA256SUMS` lists the three downloads and was signed by the owner with the release key;
  `release-signing.py verify --version 0.6.4` accepted it. The five assets downloaded back
  from the published release matched `SHA256SUMS`, which verified again, and the downloaded
  `SHA256SUMS.minisig` was byte-identical to the signed one.

## CI

Hosted CI passed every job at `921a400b` (run 46064909887), including the Windows release
job's MSI installation test: install, upgrade, refused downgrade, refused installation in
the other scope while one is installed, smoke tests, repair, removal, the all-users folder's
permissions, and the published 0.6.1, 0.6.2 and 0.6.3 MSIs upgraded in place. The runs on
main before it failed in ways that a following commit corrected: a FAT test that ran
without its file and a removal check that read a per-user product's HKLM entry as the
machine scope's (`9338f1e6`), a drive-list coalescing test that assumed an unstalled
runner (`ae9bd84b`), and a user-command probe whose 15-second guard was shorter than a
hosted runner's first Windows PowerShell start (`404dab11`).

## Whole-suite acceptance

Full-scale fixture, debug test builds with the release packages, isolated scenarios four
at a time, on the binaries of `921a400b`.

| System | Commit | Run | Passed | Warned | Skipped | Failed | Time |
| --- | --- | --- | ---: | ---: | ---: | ---: | ---: |
| Windows 11 | `921a400b` | `20261128-091528` | 114 | 2 | 3 | 0 | 1,309 s |
| Linux (WSL 2, Ubuntu 24.04, ext4) | `921a400b` | `20261128-085518` | 116 | 1 | 2 | 0 | 860 s |

The warnings are review flags in screenshots (`viewers_selection`) and `viewers_files`'
AppArmor case; the skips are the full UI matrix, gated volumes the machines do not have,
and on Windows `files_trash` and `journeys_links_readonly`.

## Not verified

- A start on a Windows computer without the Visual C++ Redistributable (the import scan
  shows that nothing needs it).
- One authorization for a folder and its subfolders with a real UAC or polkit prompt.
- Reads on a real FAT32 volume after the native plugin's fallback; the same fallback was
  measured on a UDF disc image ([content reads](../developer/content-reads.md#file-systems)).
