# F10 main menu — 8 November 2026

The main menu now lists 58 implemented actions in Files, Selection, Panels and
navigation, Tools, and Application. All actions are initially visible in the
scrolling list; the category picker can narrow it. Icons and labels align left,
configured shortcut hints align right. The menu is movable/resizable, has a close
button and dismisses on Escape or an outside click.

Commands reuse semantic keyboard dispatch and existing backend preparation and
confirmation. A shared predicate controls menu/function-bar availability; no real
target disables file operations, while a selection of real entries can still be
used when the caret is on the parent row. Unsupported archive mutations and
unavailable network connection operations are disabled. `As other panel` now also
dispatches outside the drive dropdown. Options, Jobs, About, Custom Commands
settings, Manage Hot Paths and panel view modes have configurable catalogue
actions without default keys.
