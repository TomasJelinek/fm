# 0.1.0 preview release qualification

Both application binaries were built using the checked-in optimized release
profile and Rust 1.99.1, with locked offline dependencies. Generated output and
test captures remain under `_build`; they are not committed.

| Artifact | Bytes | SHA-256 |

| Linux x86-64 `me` | 33903440 | `f8ac3a1ed2b6c0389348d2a92b177ebe29dfe4acac28915a725feb46fbdfdee4` |

Windows passed native Direct3D UI smoke/snapshot on Windows 11 25H2. The initial
ZIP passed CRC/path/content checks, executable SHA-256 comparison and an extracted
filesystem smoke test. No user preferences, toolchains, caches or intermediate
objects were included. Final archives are generated after the packaging commit
so their `BUILD-INFO.json` records the final source revision.

Ubuntu 24.04 under WSL2 passed the release filesystem and UI smoke checks,
106 native library tests (zero ignored, including isolated X11 tests), 151 engine
tests (one explicitly opt-in debug CPU benchmark ignored), and strict Clippy for
the Linux platform crate/all targets. The UI check used isolated Xvfb,
FemtoVG-WGPU on a CPU adapter, and private Noto font configuration; Czech, CJK and
joined color emoji were visually checked. This does not qualify a physical Linux
GPU/desktop or native Fedora/openSUSE installation.

ELF inspection confirmed x86-64 PIE, stripped symbols, the standard dynamic
loader, no RPATH/RUNPATH containing private build paths, and GLIBC symbols no newer
than the Ubuntu 24.04 / 2.39 baseline. `ldd` resolved the direct/transitive ELF
libraries without the QA `LD_LIBRARY_PATH`; GUI dynamically loaded dependencies
remain documented runtime requirements.

An independent review approved the X11 cleanup correction and release packaging.
A packaging review caught silent omission of indented dependency-tree lines;
the regression failed before the parser fix and all three inventory tests passed
after it. CI now runs these tests on Windows and Linux. Rust formatting,
`git diff --check` and the 100,000-byte source-size check passed (479 source files).

Archives are previews with explicit feature/platform limits. Publishing still
requires final ZIP/tar extraction, executable checksum and permission checks,
unpacked smoke tests, `SHA256SUMS`, and verification of the uploaded release assets.
