# Release 0.6.1 and its acceptance runs

Recorded on 26 November 2026. The [0.6.1 preview](../releases/0.6.1.md) was built,
tested and published from `3a83b533` (tag `v0.6.1`): any number of viewer and comparator
windows, text comparison up to 64 MiB, decoded images up to 256 MiB, faster viewer and
archive opening, the first Windows installer (MSI) and the other changes its notes list.

## Builds and packages

- Windows: the release build of `3a83b533` in a clean detached checkout, Windows 11 x64,
  with the FFmpeg 9.0.2 libraries built from the official archive with the pinned
  SHA-256. The release ZIP `midnight-explorer-0.6.1-x86_64-pc-windows-msvc.zip`
  (246,021,019 bytes, SHA-256
  `7a49ff450cf053aae0c953a7916619ff5478bf3c6a803bccd89843d51e7663c4`).
- Windows installer: `midnight-explorer-0.6.1-x86_64-pc-windows-msvc.msi` (193,454,080
  bytes, SHA-256 `42442cc491e2fd0cbf29717ec06048b88f58f1d71720e15b0b8a33ae10cbfddb`),
  built from that ZIP by `scripts/package-msi.py` in 425 s; its built-in verification
  compared every packed file with the ZIP and passed. The owner installed it, started
  Midnight Explorer from the Start menu and uninstalled it on Windows; upgrade, repair
  and ICE validation remain open (REL-05).
- Linux: the release build and package of `3a83b533` in a WSL 2 Ubuntu 24.04 clone,
  `midnight-explorer-0.6.1-x86_64-unknown-linux-gnu.tar.gz` (207,563,137 bytes, SHA-256
  `278d730bcef1ac9767defffb25664092331ae47ee5ee78e964aea76ff12305b0`).
- Both archives carry `LICENSE.txt` (Windows) or `LICENSE` (Linux) and a `README.txt`
  that begins "Midnight Explorer 0.6.1"; each `BUILD-INFO.json` names `3a83b533`.
- Before publishing, the ZIP's `midnight-explorer` and `midnight-elevated-listing`
  executables were byte-identical to the tested release build, and the ZIP held no PDB,
  ILK or object files.
- `SHA256SUMS` lists the three downloads and was signed by the owner with the release
  key; `release-signing.py verify --version 0.6.1` accepted it. The five assets downloaded
  back from the published release matched `SHA256SUMS`, which verified again, and the
  downloaded `SHA256SUMS.minisig` was byte-identical to the signed one.

## Whole-suite acceptance at 3a83b533

Full-scale fixture, debug test builds with the release packages of `3a83b533`, isolated
scenarios four at a time; the Windows and Linux runs overlapped.

| System | Run | Passed | Warned | Skipped | Failed | Time |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| Windows 11 | `20261126-114413` | 113 | 2 | 3 | 1 | 1,473 s |
| Linux (WSL 2, Ubuntu 24.04, ext4) | `20261126-112728` | 115 | 2 | 2 | 0 | 1,020 s |

The warnings are review flags in screenshots and `viewers_files`' AppArmor case; the skips
are gated volumes and tools the machines do not have (no 7-Zip program for one encrypted
names check), and on Windows `journeys_links_readonly`, which checks Linux links and modes.

The Windows failure was `find_archives`' search of 300 small ZIPs and one ZIP of 20,000
members: it ended "Incomplete · 300 found · 20 899 examined" without the large ZIP's
match. The scenario passed when run alone right after (run `20261126-121102`, 45 s). Its
cause is not yet known; the scenario did not print Find's details, and the investigation
is open.
