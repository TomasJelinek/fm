# Release 0.5.4 and its acceptance runs

Recorded on 25 November 2026. The [0.5.4 preview](../releases/0.5.4.md) was built,
tested and published from `510d9abc` (tag `v0.5.4`), a security and fixes release after
[0.5.3](2026-11-25-release-0.5.3.md): installation securing that a junction or symbolic
link cannot redirect (`ab3c2bef`, `dae80798`), the ordering fixes of the HTML viewer's
helper, a closed viewer window's slot and an archive selection's queue slot, and faster
Find sorting.

## Builds and packages

- Windows: the release build of `510d9abc` in a clean detached checkout (moved there from
  the 0.5.3 checkout), Windows 11 x64; the release ZIP
  `midnight-explorer-0.5.4-x86_64-pc-windows-msvc.zip` (259,056,684 bytes, SHA-256
  `8a7aa5c51b1c5ded4bb7145cafb8b2efcfe6cd34c54466c72f13137c591dc5c8`), with the FFmpeg
  9.0.2 libraries built for 0.5.3.
- Linux: the release build and package of `510d9abc` in a WSL 2 Ubuntu 24.04 clone,
  `midnight-explorer-0.5.4-x86_64-unknown-linux-gnu.tar.gz` (435,568,527 bytes, SHA-256
  `6df93399ebd54981df7fac0107d30a4445bb76d83e5747e52e93db6276403618`).
- Both archives carry `LICENSE.txt` (Windows) or `LICENSE` (Linux) and a `README.txt`
  that begins "Midnight Explorer 0.5.4"; each `BUILD-INFO.json` names `510d9abc`.
- Before publishing, the unpacked archives' `midnight-explorer` and
  `midnight-elevated-listing` executables were byte-identical to the tested release
  builds on both systems; the ZIP held no PDB, ILK or object files; its `thumbnailers`
  files named no grant for the workers' AppContainer; and the ignored extracted-installation
  tests (`midnight-thumbnail-host` integration `extracted_installation`,
  `midnight-media-host` `extracted_installation`) passed from a copy of that folder in a
  private profile installation.
- `SHA256SUMS` was signed by the owner with the release key; `release-signing.py
  verify --version 0.5.4` accepted it, and the four assets downloaded back from the
  published release matched `SHA256SUMS`, verified again, and the downloaded
  `SHA256SUMS.minisig` was byte-identical to the signed one.
