# Release 0.5.2 and its acceptance runs

Recorded on 24 November 2026. The [0.5.2 preview](../releases/0.5.2.md) was built,
tested and published from `1341a7ff` (tag `v0.5.2`); main moved on afterwards with
the Linux network sign-in (`2b61812e`) and later commits, which are not part of it.

## Builds and packages

- Windows: release and debug builds of `1341a7ff` in a clean detached checkout,
  Windows 11 x64; the release ZIP `midnight-explorer-0.5.2-x86_64-pc-windows-msvc.zip`
  (258,864,653 bytes, SHA-256 `f1c2d010ee37c747ec3670dfaf7e6bfc3db61b5810101aece7c1071123117fd5`).
- Linux: the release build and package of `1341a7ff` in a WSL 2 Ubuntu 24.04 clone,
  `midnight-explorer-0.5.2-x86_64-unknown-linux-gnu.tar.gz` (435,420,344 bytes, SHA-256
  `ddfe48dc9812b0c4b42764c7f8c92ae2ce064027b04ad105a9788ad70fa18262`).
- Both archives carry `LICENSE.txt` (Windows) or `LICENSE` (Linux) and a `README.txt`
  that begins "Midnight Explorer 0.5.2"; each `BUILD-INFO.json` names `1341a7ff`.
- Before publishing, the unpacked ZIP's `midnight-explorer.exe` and
  `midnight-elevated-listing.exe` were byte-identical to the tested release build; its
  `thumbnailers` files named no grant for the workers' AppContainer (as any ZIP
  extraction leaves them); and the ignored extracted-installation tests

  `extracted_installation`) started the video thumbnail helper and both playback

- `SHA256SUMS` was signed by the owner with the release key; `release-signing.py
  verify --version 0.5.2` accepted it, and the four assets downloaded back from the
  published release matched `SHA256SUMS` and verified again.

packages of `1341a7ff`.

The warnings are `viewers_files`' AppArmor case (no AppArmor on Windows or in WSL); the
skips are gated volumes and tools the machines do not have. No failure was a product
defect of `1341a7ff`:

- **Stale after `d75e82b1` (Find):** `tools_find_results` and `find_budgets` expected the
  former 10,000-result limit; `find_feed_panel` and `viewers_combinations` expected
  refusals that became actions on a fed list (Compare files, Make File List, checksums,
  Rename and others); `find_archives` compared the whole error text, to which the
  backend's feed preparation now adds "Operation: feed search results".
- **Stale after `b70cf8df` (Compare marks):** `tools_main_menu`, `shortcuts_catalog` and
  `shortcuts_footer` had no probe for "Clear comparison marks" (`panel.compare-clear`).
- **Linux only, cosmetic:** `ui_review` and `ui_polish_dialogs` flagged the Attributes
  dialog's permission bits ("Bits:" off the SUID check box's centre, a 13 px gap where the
  matrix uses 6 px) under the alignment checks U-K32 and U-K39 added that day, plus one
  gate false positive (U-K38 counting a gap the layout cannot use).
- **Windows, not reproduced:** `viewers_selection` once could not copy a whole CSV file
  ("Content read failed"); three reruns passed 83 of 83 checks. The missing retry and the
  hidden native error are backlog item VIEW-10.
