# Midnight Explorer 0.5.3 — preview

A follow-up to the [0.5.2 preview](https://github.com/TomasJelinek/fm/releases/tag/v0.5.2):
scrolling glide that keeps the scrolling speed, Copy and Move keeping times and
attributes by default, sign-in to SMB devices on Linux, a glowing Moon, faster large
selections and lists, and fixes.

## Downloads

- **Windows x64:** `midnight-explorer-0.5.3-x86_64-pc-windows-msvc.zip`. Extract the
  complete archive to a folder and run `midnight-explorer.exe`; keep the `viewers`,
  `filesystems` and `thumbnailers` folders beside it. In a folder that other accounts can
  change (for example one created directly under `C:\`), the application runs and offers
  once to secure the folder or copy itself into your profile. Targets Windows 10 22H2 and
  Windows 11; the executable is unsigned. The Microsoft Visual C++ x64 runtime is
  required if it is not already installed.
- **Linux x86-64:** `midnight-explorer-0.5.3-x86_64-unknown-linux-gnu.tar.gz`. Extract it
  with tar and run `./midnight-explorer` in an X11 or Wayland desktop. Built on Ubuntu
  24.04 (glibc 2.39 baseline); the archive's README lists the runtime packages.
- **`SHA256SUMS`** and **`SHA256SUMS.minisig`:** the checksums of both archives and their
  minisign signature by the release key. 0.5.1 and 0.5.2 offer this version through their
  update check and install it only when the signature and checksums match.

## Upgrading from 0.5.2

- Use the update button beside Options and About, or About › Check for updates; or
  extract the new archive over a copy of the old folder.
- Copy and Move now keep times and attributes unless you turned that off: an explicit
  saved choice and the option in each Copy or Move dialog still apply.

## New and changed

- **Scrolling glide keeps the scrolling speed.** With glide on, a spin of the wheel or a
  held scroll key covered less ground than with glide off: a pending distance over
  2,400 pixels was dropped, every glide started slowly, and each notch of a fast spin
  started a whole new glide. Now every input travels its whole distance and reaches it
  within about one glide; a glide starts at its full speed and eases out, so a fast spin
  keeps up with glide off and a held Page Down at Very long no longer stops 43 % short.
  The document viewers no longer paint parts of the page again after a fast turn.
- **Copy and Move keep times and attributes by default** (Options › General, and each
  dialog's option).
- **Linux: sign in to SMB devices and shares** from Network Neighborhood when they ask
  for credentials.
- **The Moon glows:** the application icon and the About dialog's Moon have a warm yellow
  aura.
- **Compare Directories** keeps the badges and their reasons of the top-level folders
  also without Compare subfolders, and an unexamined folder no longer implies that the
  folders inside it match.
- **Faster with large lists:** Select all and Deselect all in Checksums tell the list once
  instead of once per row; Alt+Up and Alt+Down between selected members of a large
  archive folder no longer look at every selected member; Find in a command's output no
  longer copies every line; the Jobs window updates a running job's row instead of
  rebuilding every row; the drag-and-drop helper no longer wakes four times a second while
  idle; a closed file comparison window frees its memory at once.

## Fixes

- Find's filename mask history button and the two disclosure buttons of Custom Commands
  showed an empty box on Windows (a symbol the font lacks); they show arrows. A new test
  fails on any shown character that the fonts cannot draw.
- Wayland with GPU rendering: scrolling no longer stalls, and a document scrolled to its
  very edge no longer bounces back.
- The Attributes dialog's permission bits on Linux line up with the permission matrix.

## Current limitations

- Archives are read-only, and RAR is not supported.
- On Linux, native Wayland drag and drop with other applications is off unless
  `MIDNIGHT_WAYLAND_DND=1`; X11 and XWayland use XDND.
- Compare Directories remembers its options only until the application closes.
- Network Neighborhood asks for credentials on Linux only, and has not been run against a
  real SMB server.
- macOS is not implemented, and the Windows executable is unsigned.
