# Midnight Explorer 0.1.0 — preview

First downloadable preview of the Rust/Slint dual-pane file manager.

## Downloads

- **Windows x64:** `midnight-explorer-0.1.0-x86_64-pc-windows-msvc.zip`.
  Extract and run `me.exe`. Targets Windows 10 22H2 / Windows 11; native validation
  uses Windows 11 25H2. The executable is unsigned. The Microsoft Visual C++ x64
  runtime is required if it is not already installed.
- **Linux x86-64:** `midnight-explorer-0.1.0-x86_64-unknown-linux-gnu.tar.gz`.
  Extract and run `./me` in an X11 or Wayland desktop. Built on Ubuntu 24.04;
  the distributed binary targets the glibc 2.39 baseline. Runtime package and
  optional desktop-launcher instructions are inside the archive. Fedora/openSUSE
  are compatibility targets whose native desktop qualification remains pending.
- **`SHA256SUMS`:** verify archive integrity after downloading. Checksums are not
  a replacement for code signing.

Rust and build tools are not needed to run either downloaded application.
The archives include dependency notices/licenses, source revision and executable
checksum metadata, requirements, shortcuts and a feature-status document.

## Available now

- Native Windows/Linux panels, tabs, bookmarks, multiselection, locale-aware
  sorting, background folder sizes and filesystem refresh.
- Filename-prefix search, optional quick filtering, and panel filters using
  wildcards, regex or typed expressions.
- Background clipboard and drag/drop copying with a bounded queue, progress,
  cancellation and independent SHA-256 destination readback.
- Confirmed rename, empty-file/recursive-folder creation, Trash/permanent deletion,
  attributes/timestamps/case changes, and directory comparison.
- Configurable shortcuts, themes, density/fonts and a command line with shell
  selection and persisted history.
- X11 drag/drop teardown now waits for the server to restore the host's registration,
  fixing a race detected during release validation.

## Current limitations

Internal viewers, configurable F4 editing, complete F5/F6 Copy/Move dialogs,
overwrite/merge, recursive Find, archive/network-discovery plugins and inline
directory trees remain pending. Copy currently supports ordinary files/folders,
keeps sources, and offers skip/new-name handling for conflicts. It does not copy
links or preserve all metadata. Thumbnails currently use large icons.

External Linux drag/drop supports X11/XWayland; native Wayland currently supports
internal panel dragging only. The software renderer has known bitmap-emoji
limitations. macOS is not implemented.
