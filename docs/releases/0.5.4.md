# Midnight Explorer 0.5.4 — preview

A security and fixes release after the [0.5.3 preview](https://github.com/TomasJelinek/fm/releases/tag/v0.5.3).
Update if you run Midnight Explorer from a folder that other accounts can change.

## Downloads

- **Windows x64:** `midnight-explorer-0.5.4-x86_64-pc-windows-msvc.zip`. Extract the
  complete archive to a folder and run `midnight-explorer.exe`; keep the `viewers`,
  `filesystems` and `thumbnailers` folders beside it. In a folder that other accounts can
  change (for example one created directly under `C:\`), the application runs and offers
  once to secure the folder or copy itself into your profile. Targets Windows 10 22H2 and
  Windows 11; the executable is unsigned. The Microsoft Visual C++ x64 runtime is
  required if it is not already installed.
- **Linux x86-64:** `midnight-explorer-0.5.4-x86_64-unknown-linux-gnu.tar.gz`. Extract it
  with tar and run `./midnight-explorer` in an X11 or Wayland desktop. Built on Ubuntu
  24.04 (glibc 2.39 baseline); the archive's README lists the runtime packages.
- **`SHA256SUMS`** and **`SHA256SUMS.minisig`:** the checksums of both archives and their
  minisign signature by the release key. 0.5.1, 0.5.2 and 0.5.3 offer this version through
  their update check and install it only when the signature and checksums match.

## Upgrading from 0.5.3

- Use the update button beside Options and About, or About › Check for updates; or
  extract the new archive over a copy of the old folder.

## Security

- **Securing a shared installation folder can no longer change files outside it.** When
  you chose to secure an installation folder that other accounts could change, another
  account that could still write in a folder below it could replace that folder with a
  junction (Windows) or a symbolic link (Linux) while the folder was being secured, and
  redirect the change to your own files elsewhere: on Windows they could lose their
  protection and inherit the permissions of their parent folder, on Linux a file could
  lose its group and other write bits or take another file's mode. Every object is now
  changed through a handle that does not follow links, and only when it is really inside
  the installation; anything else is reported and left unchanged. Versions up to 0.5.3
  are affected only when you secure a folder that other accounts can change.

## Fixes

- The HTML viewer's helper no longer ends without its last message, so a page that
  cannot be opened shows its own error instead of "Chromium disconnected".
- Closing one of four viewer windows and opening another at once no longer reports the
  four-window limit.
- A second archive selection right after the first is no longer refused as busy.
- Compare Directories, the update check and the main menu say what they do: the Compare
  subfolders option, "at most once every 20 hours", downloads "from GitHub", and
  "Invert top-level files and folders".

## Faster

- Sorting 100,000 Find results by name, extension or path is 5 to 11 times faster.
- Sorting a large panel again copies its rows once instead of twice.

## Current limitations

- Archives are read-only, and RAR is not supported.
- On Linux, native Wayland drag and drop with other applications is off unless
  `MIDNIGHT_WAYLAND_DND=1`; X11 and XWayland use XDND.
- Compare Directories remembers its options only until the application closes.
- Network Neighborhood asks for credentials on Linux only, and has not been run against a
  real SMB server.
- macOS is not implemented, and the Windows executable is unsigned.
