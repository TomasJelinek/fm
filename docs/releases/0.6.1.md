# Midnight Explorer 0.6.1 — preview

An update to the [0.6.0 preview](https://github.com/TomasJelinek/fm/releases/tag/v0.6.0):
any number of viewer and comparator windows, larger files in comparisons and the image
viewer, faster viewer and archive opening, a Windows installer (MSI), volume and mute
in the video viewer, and refreshed application icons.

## Downloads

- **Windows x64, installer:** `midnight-explorer-0.6.1-x86_64-pc-windows-msvc.msi`. New
  in this release: installs for your account only, without administrator rights, into
  `%LOCALAPPDATA%\Programs\Midnight Explorer (MSI)`, with a Start menu entry and an
  entry under Settings › Apps › Installed apps to repair or remove it. Removing it
  leaves your settings. A copy installed this way updates by running a newer release's
  MSI. The installer is unsigned.
- **Windows x64, archive:** `midnight-explorer-0.6.1-x86_64-pc-windows-msvc.zip`. Extract
  the complete archive to a folder and run `midnight-explorer.exe`; keep the `viewers`,
  `filesystems` and `thumbnailers` folders beside it. In a folder that other accounts can
  change (for example one created directly under `C:\`), the application runs and offers
  once to secure the folder or copy itself into your profile. Targets Windows 10 22H2 and
  Windows 11; the executable is unsigned. Both Windows downloads need the Microsoft
  Visual C++ x64 runtime if it is not already installed.
- **Linux x86-64:** `midnight-explorer-0.6.1-x86_64-unknown-linux-gnu.tar.gz`. Extract it
  with tar and run `./midnight-explorer` in an X11 or Wayland desktop. Built on Ubuntu
  24.04 (glibc 2.39 baseline); the archive's README lists the runtime packages.
- **`SHA256SUMS`** and **`SHA256SUMS.minisig`:** the checksums of the three downloads and
  their minisign signature by the release key. 0.5.1 to 0.6.0 offer this version through
  their update check and install it only when the signature and checksums match.

## Upgrading from 0.6.0

- Use the update button beside Options and About, or About › Check for updates; or
  extract the new archive over a copy of the old folder. The MSI installs separately
  from an extracted copy and does not replace it.
- Settings are kept as they are.

## New and changed

- **Any number of windows.** Viewer and comparator windows are no longer limited (they
  were four and two): open as many as you like. Each text, source or Markdown viewer runs
  its own plugin instance with its own bounds, without a per-plugin limit. Comparisons
  prepare two at a time; another one shows "Waiting for other comparisons to finish…"
  and starts when one is ready, and closing it stops the wait.
- **Larger files.** Text comparison takes files up to 64 MiB (was 32 MiB). The image
  viewer and image comparison decode images up to 256 MiB of pixels (was 128 MiB, about
  67 megapixels now), with up to 1 GiB of memory per image worker. A JPEG file larger
  than 96 MiB is not opened in full, as it would exceed that memory; its thumbnail still
  shows.
- **Faster viewers.** A viewer opened again in a session shows its file about three to
  four times sooner on Windows: text, source, Markdown and hex in about 70–90 ms (was
  about 300 ms), images and PDF in about 110–170 ms (was 300–350 ms), and HTML in about
  430 ms (was 630 ms). The next viewer window is prepared while the application is idle,
  never while you type, click or scroll; image and PDF viewers check their package once
  per opening instead of several times, and a new window no longer rebuilds its drawing
  surface for a resize that changes nothing.
- **Faster archives.** Archives of many small files show their first folder sooner: with
  100,000 files, about 20% sooner for 7z, 13% for ZIP and 5% for tar.gz.
- **Video viewer:** a volume slider and a mute button; M mutes and unmutes.
- **Windows installer:** see Downloads.
- **Viewer windows open over the main window.** On X11 window managers that report
  their frames' shadows as part of the frame, a viewer or comparator now opens exactly
  over the main window instead of shifted by the shadow. On Wayland the desktop chooses
  where a new window opens; a maximized main window gives a maximized viewer.
- **Application icons:** Harvest Navigator, Origami Trail and Interleave were redrawn;
  Origami Trail now shows grid and list panes.
- **Limits reference:** the [limits](https://github.com/TomasJelinek/fm/blob/v0.6.1/docs/LIMITS.md)
  page lists every limit of the application, its value and what happens when it is
  reached.

## Fixes

- A closed comparator no longer holds back the next one for a moment (COMPARE-03).
- Shutting down while a drag from another application waits for its drop returns the
  capacity reserved for it at once.
- Command icon snapshots that no saved setting names any more are removed.
- Copying many small files on Windows is faster: each volume's checks run once per
  batch, and a destination folder's final path is read once.

## Current limitations

- Archives are read-only, and RAR is not supported.
- On Linux, native Wayland drag and drop with other applications is off unless
  `MIDNIGHT_WAYLAND_DND=1`; X11 and XWayland use XDND.
- Compare Directories remembers its options only until the application closes.
- Network Neighborhood asks for credentials on Linux only, and has not been run against a
  real SMB server.
- Each open viewer or comparator window keeps its own worker and, for images, PDF, HTML
  and video, its own helper process: many large documents open at once use memory
  accordingly.
- macOS is not implemented, and the Windows executable and installer are unsigned.
