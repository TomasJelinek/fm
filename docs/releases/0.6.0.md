# Midnight Explorer 0.6.0 — preview

A feature release after the [0.5.4 preview](https://github.com/TomasJelinek/fm/releases/tag/v0.5.4):
themes that follow the system's light or dark appearance, an application icon of your
choice, a Browse button for Copy and Move destinations, a clearer progress window, a
Linux drive list with GVfs locations, smaller downloads and many viewer fixes.

## Downloads

- **Windows x64:** `midnight-explorer-0.6.0-x86_64-pc-windows-msvc.zip`. Extract the
  complete archive to a folder and run `midnight-explorer.exe`; keep the `viewers`,
  `filesystems` and `thumbnailers` folders beside it. In a folder that other accounts can
  change (for example one created directly under `C:\`), the application runs and offers
  once to secure the folder or copy itself into your profile. Targets Windows 10 22H2 and
  Windows 11; the executable is unsigned. The Microsoft Visual C++ x64 runtime is
  required if it is not already installed.
- **Linux x86-64:** `midnight-explorer-0.6.0-x86_64-unknown-linux-gnu.tar.gz`. Extract it
  with tar and run `./midnight-explorer` in an X11 or Wayland desktop. Built on Ubuntu
  24.04 (glibc 2.39 baseline); the archive's README lists the runtime packages.
- **`SHA256SUMS`** and **`SHA256SUMS.minisig`:** the checksums of both archives and their
  minisign signature by the release key. 0.5.1 to 0.5.4 offer this version through their
  update check and install it only when the signature and checksums match.

## Upgrading from 0.5.4

- Use the update button beside Options and About, or About › Check for updates; or
  extract the new archive over a copy of the old folder.
- Theme choices made in earlier versions are kept as they were; the new light and dark
  pair applies when you choose it.
- The Moon application icon is replaced by Harvest Navigator, the new default; settings
  saved with the Moon open with Harvest Navigator.

## New and changed

- **Appearance follows the system.** Options › Appearance takes a dark and a light theme
  and switches with the system's appearance; 20 new palettes bring the choice to 46,
  grouped by light and dark.
- **Application icon.** Harvest Navigator, a compass needle and gold crescent on a blue
  folder, is the new default application icon, replacing the Moon. Options › Appearance
  offers three icons (Harvest Navigator, Origami Trail, Interleave) with a live preview.
- **Copy and Move:** a Browse button beside the destination chooses a folder; the
  folder picker starts at the folder already typed.
- **Delete:** where the Recycle Bin or Trash cannot take an item, Delete offers to delete
  it permanently instead of failing.
- **Progress window:** the time remaining sits right under the percentage, and the speed
  chart's legend shows the write and verify speeds.
- **Panels:** a folder shown as a row updates its expand icon after a Delete, a new folder
  or a drop into it; the strip beside a panel's rows takes drops into its folder; deletions
  and freed space show promptly after watched changes.
- **Linux drive list:** GVfs locations (opened network shares and devices) appear by name
  instead of the empty GVfs bridge; long drive names are shortened, with the whole name in
  the tooltip and the dropdown. A sign-in to an SMB server is remembered for the session.
- **Custom Commands:** drafts and working folders inside native archives are kept;
  Windows batch commands run in every output mode.
- **Viewers:** faster opening; very long rows fill the window at rest and follow
  scrollbar positions; wheel steps that arrive while a page loads are no longer lost; the
  HTML viewer's wheel glide pauses through a page stall instead of ending.
- **Comparator:** keyboard navigation between differences was improved, and directory
  comparison badges stay through background refreshes.
- **Smaller downloads:** release builds ship without debug symbols, and the HTML viewer
  ships only the English Chromium locale.
- **Linux on native Wayland:** frames present in Mailbox mode where the compositor offers
  it, and rendering pipelines are kept across frames.

## Fixes

- Viewer windows return their memory sooner: prepared text strips are dropped when a
  non-text view opens, a closed window is released at once, freed strip memory is
  returned without waiting for another window, and each window looks up at most one link
  target at a time.
- Update downloads of versions that were never installed are removed when a new download
  starts.

## Current limitations

- Archives are read-only, and RAR is not supported.
- On Linux, native Wayland drag and drop with other applications is off unless
  `MIDNIGHT_WAYLAND_DND=1`; X11 and XWayland use XDND.
- Compare Directories remembers its options only until the application closes.
- Closing a comparator and opening another at once can be refused for a moment
  (COMPARE-03).
- Network Neighborhood asks for credentials on Linux only, and has not been run against a
  real SMB server.
- macOS is not implemented, and the Windows executable is unsigned.
