# Midnight Explorer 0.6.2 — preview

A fix release after the [0.6.1 preview](https://github.com/TomasJelinek/fm/releases/tag/v0.6.1):
drives that appear and disappear at once, a Move to Trash question that can no longer
hide, Find that no longer skips files your antivirus has just scanned, folder sizes that
survive unreadable entries and sort properly, and steadier comparisons.

## Downloads

- **Windows x64, installer:** `midnight-explorer-0.6.2-x86_64-pc-windows-msvc.msi`.
  It now asks who it is for: **Just for me** installs without administrator rights into
  `%LOCALAPPDATA%\Programs\Midnight Explorer (MSI)` and upgrades an installed 0.6.1 MSI;
  **For all users** asks for administrator approval and installs into
  `C:\Program Files\Midnight Explorer (MSI)`. Each adds a Start menu entry and an entry
  under Settings › Apps › Installed apps to repair or remove it; removing it leaves your
  settings. The installer is unsigned.
- **Windows x64, archive:** `midnight-explorer-0.6.2-x86_64-pc-windows-msvc.zip`. Extract
  the complete archive to a folder and run `midnight-explorer.exe`; keep the `viewers`,
  `filesystems` and `thumbnailers` folders beside it. Targets Windows 10 22H2 and
  Windows 11; the executable is unsigned. Both Windows downloads need the Microsoft
  Visual C++ x64 runtime if it is not already installed.
- **Linux x86-64:** `midnight-explorer-0.6.2-x86_64-unknown-linux-gnu.tar.gz`. Extract it
  with tar and run `./midnight-explorer` in an X11 or Wayland desktop. Built on Ubuntu
  24.04 (glibc 2.39 baseline); the archive's README lists the runtime packages.
- **`SHA256SUMS`** and **`SHA256SUMS.minisig`:** the checksums of the three downloads and
  their minisign signature by the release key. 0.5.1 to 0.6.1 offer this version through
  their update check and install it only when the signature and checksums match.

## Upgrading from 0.6.1

- Use the update button beside Options and About, or About › Check for updates; or
  extract the new archive over a copy of the old folder; or run the new MSI over an
  installed 0.6.1 MSI.
- Settings are kept as they are.

## New and changed

- **Drives come and go at once.** The drive bar and the drives list follow the system's
  notifications: a USB stick, a card, a mapped network drive or a mount appears or
  disappears within a fraction of a second (it took up to 45 seconds), its name and free
  space following once they are read. A panel showing a removed drive goes straight to
  the nearest folder that still opens.
- **Retry with authorization works from your own installation.** Opening a folder your
  account cannot read offers Windows' administrator prompt also from a just-for-you MSI
  or a ZIP extracted in your profile: the application starts only the exact helper it
  shipped with, which it checks by content before asking. Where the prompt cannot work
  (the helper is missing or altered, or other accounts can change the installation),
  the message says so instead of offering it.
- **Sorting by size orders folders.** Folders whose size was calculated are ordered by it,
  partial totals included; folders without a size follow, by name. A panel sorted by size
  re-sorts itself as calculated sizes arrive, keeping the cursor and the selection on
  their items. Find's Feed to panel list orders folders by their totals as well.
- **Light desktops** start with the Light theme.
- **Application icons** are larger in the taskbar.

## Fixes

- **Move to Trash no longer waits behind its own progress window.** Where the Recycle Bin
  or Trash refuses an item (for example a drive set to "Don't move files to the Recycle
  Bin"), the question whether to delete it permanently opens in its own window above the
  progress window; Resolve brings it back, and the progress window says the job waits for
  an answer.
- **Find no longer skips files that antivirus software has just scanned.** A scan can tag
  a file with metadata, which moved its change time; Find now accepts a file whose change
  time alone moved, as the viewers already do, and still notices any change of its size,
  write time or attributes.
- **Archives, viewers and thumbnails start reliably while several copies of the
  application run.** Starting a helper no longer re-creates the helpers' sandbox profile
  each time, which could fail when two copies started helpers at the same moment.
- **Folder sizes keep counting past unreadable entries.** An entry whose type could not be
  read no longer stops the rest of its folder from being listed and counted; the total is
  marked partial.
- **Comparisons:** an open that waits on a slow network share no longer holds back other
  comparisons; replacing a waiting comparison's files takes effect at once; "Preparing
  the comparison…" follows the wait.
- **Viewer windows** that you move or resize right after they open are left where you put
  them.
- **Thumbnails** of JPEG files over 96 MiB are refused with a message instead of stopping
  their helper.
- **The Cannot open folder message** keeps its button captions while they fit.

## Current limitations

- Archives are read-only, and RAR is not supported.
- On Linux, native Wayland drag and drop with other applications is off unless
  `MIDNIGHT_WAYLAND_DND=1`; X11 and XWayland use XDND. GVfs locations still appear in the
  drives list on its regular refresh rather than at once.
- Compare Directories remembers its options only until the application closes.
- Network Neighborhood asks for credentials on Linux only, and has not been run against a
  real SMB server.
- Each open viewer or comparator window keeps its own worker and, for images, PDF, HTML
  and video, its own helper process: many large documents open at once use memory
  accordingly.
- macOS is not implemented, and the Windows executable and installer are unsigned.
