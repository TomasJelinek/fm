# Midnight Explorer 0.5.2 — preview

A follow-up to the [0.5.1 preview](https://github.com/TomasJelinek/fm/releases/tag/v0.5.1):
video thumbnails and playback work in installations extracted from the ZIP, the free
space follows the disk, Copy and Move can keep times and attributes, archives join the
folder history, and many smaller improvements and fixes.

## Downloads

- **Windows x64:** `midnight-explorer-0.5.2-x86_64-pc-windows-msvc.zip`. Extract the
  complete archive to a folder and run `midnight-explorer.exe`; keep the `viewers`,
  `filesystems` and `thumbnailers` folders beside it. In a folder that other accounts can
  change (for example one created directly under `C:\`), the application runs and offers
  once to secure the folder or copy itself into your profile. Targets Windows 10 22H2 and
  Windows 11; the executable is unsigned. The Microsoft Visual C++ x64 runtime is
  required if it is not already installed.
- **Linux x86-64:** `midnight-explorer-0.5.2-x86_64-unknown-linux-gnu.tar.gz`. Extract it
  with tar and run `./midnight-explorer` in an X11 or Wayland desktop. Built on Ubuntu
  24.04 (glibc 2.39 baseline); the archive's README lists the runtime packages.
- **`SHA256SUMS`** and **`SHA256SUMS.minisig`:** the checksums of both archives and their
  minisign signature by the release key. 0.5.1 offers this version through its update
  check and installs it only when the signature and checksums match.

## Upgrading from 0.5.1

- Use the update button beside Options and About, or About › Check for updates; or
  extract the new archive over a copy of the old folder.
- Settings files written by 0.5.2 can use schema 41 to 43 (Find history and placement,
  saved locations inside archives inside archives, the Copy and Move default for times
  and attributes), which 0.5.1 cannot read; keep a copy of the settings file if you may
  go back to 0.5.1.

## Fixed in 0.5.2

- **Video thumbnails and playback on Windows.** The video helpers run in a sandbox that
  Windows lets load only libraries it may read. In 0.5.1 only the build scripts granted
  that read permission, and a ZIP archive cannot carry it, so installations extracted
  from the 0.5.1 ZIP showed "could not load its libraries (access denied):
  …\thumbnailers\avcodec-63.dll" and no video thumbnails or playback. The application
  now adds that permission itself in a folder only you can change: read and execute, for
  the sandbox only, on the five FFmpeg libraries and the two playback helpers. In a
  folder that other accounts can change, use Secure this folder or copy the
  installation into your profile first.
- **Free space** in the panels' details strip now follows the disk while the application
  runs: after a copy, move, delete or extraction on that volume, when another program
  writes to it (every few seconds on internal disks, on window focus on network and
  removable drives) and after a tree refresh. It no longer blanks while a folder is
  re-read.
- **Folder links** such as My Music or Application Data no longer show an error badge or
  fail to expand: they are listed through their target, as when they are opened.
- **Updates:** an update that confirmed its start late no longer shows "Updated to
  version …" at every start; the downloaded archive is extracted from the same handle
  whose checksum was verified; long or huge HTTP headers are handled; a new version's
  start is confirmed when its window shows, not when its settings are read.
- **Compare Directories:** a child that one side cannot read leaves its counterpart "not
  compared completely" (?) instead of "only here".
- **Archives:** the archive helpers are bounded in the data and time one request may
  take, and opening an archive's listing or password check can be cancelled.
- **Viewers:** quick page and zoom keys in document viewers all count; the HTML viewer's
  navigation buttons follow the window's size.
- Checksums, folder sizes on network shares, New file and job pausing: fixes found in
  the code review of these areas.

## New and changed

- **Copy and Move: preserve times and attributes.** A dialog option (default in Options
  › General) gives every copied file and every folder the copy creates its source's
  times and attributes: created, modified and accessed time and Read-only, Hidden,
  System and Archive on Windows; modified and accessed time and the permission bits on
  Linux. Archive members keep their recorded time. What a destination cannot store is a
  warning, not an error. Off by default, as in Salamander.
- **Progress window:** the write speed (and the verify speed when copies are checked)
  stands beside the percentage; the speed chart keeps its scale steady; the current
  file's folder and name are on separate lines; the Details button is gone (Copy details
  has everything); progress updates twice as often.
- **Compare Directories:** pointing at a mark says what differs ("Larger here: 64,293 vs
  63,880 bytes", "Newer here: …", "Content differs (first difference at byte 4,096)").
  The × at the end of the result line, Escape, Ctrl+Shift+F11 or Tools › Clear comparison
  marks removes every mark.
- **Archives in the folder history:** entering an archive, also one inside another, is a
  step of Back and Forward; Back after leaving an archive opens it again at the same
  folder. Hot Paths and saved tabs keep locations up to four archives deep and show
  them like the path bar.
- **Find** remembers its window placement and the recent filename masks, no longer stops
  at a fixed number of examined entries (it keeps up to 100,000 results), and a fed
  panel supports Make File List, checksums, Compare files, Rename and more.
- **Windows and dialogs:** every window's neighbouring controls are aligned; the Options
  pages are shorter; Checksums › Verify has a square Browse button beside its path; the
  panel's View and Sort pickers turn compact only when the drive buttons need the room.
- **Custom Commands:** icons are imported through symbolic links.

## Current limitations

- Archives are read-only, and RAR is not supported.
- On Linux, native Wayland drag and drop with other applications is off unless
  `MIDNIGHT_WAYLAND_DND=1`; X11 and XWayland use XDND.
- Compare Directories remembers its options only until the application closes.
- Network Neighborhood has no sign-in prompt and has not been run against a real SMB
  server.
- macOS is not implemented, and the Windows executable is unsigned.
