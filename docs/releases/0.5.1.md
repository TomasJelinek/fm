# Midnight Explorer 0.5.1 — preview

A follow-up to the [0.5.0 preview](https://github.com/TomasJelinek/fm/releases/tag/v0.5.0)
with fixes for what 0.5.0 got wrong, a rewritten Compare Directories, an HTML viewer
that works as a small browser, signed self-updates, and many smaller improvements.

## Downloads

- **Windows x64:** `midnight-explorer-0.5.1-x86_64-pc-windows-msvc.zip`. Extract the
  complete archive to a folder and run `midnight-explorer.exe`; keep the `viewers`,
  `filesystems` and `thumbnailers` folders beside it. Any folder works now: in a folder
  that other accounts can change (for example one created directly under `C:\`), the
  application runs and offers once to secure the folder or copy itself into your profile.
  Targets Windows 10 22H2 and Windows 11; the executable is unsigned. The Microsoft
  Visual C++ x64 runtime is required if it is not already installed.
- **Linux x86-64:** `midnight-explorer-0.5.1-x86_64-unknown-linux-gnu.tar.gz`. Extract it
  with tar and run `./midnight-explorer` in an X11 or Wayland desktop. Built on Ubuntu
  24.04 (glibc 2.39 baseline); the archive's README lists the runtime packages.
- **`SHA256SUMS`** and **`SHA256SUMS.minisig`:** the checksums of both archives and their
  minisign signature by the release key. From this version on, the application's update
  check installs only builds whose signature and checksums match its built-in key.

## Upgrading from 0.5.0

- The executable is renamed: `me.exe` is now `midnight-explorer.exe` (Linux: `me` is now
  `midnight-explorer`). Settings stay where they were; re-point shortcuts, pinned
  taskbar items and "Open with" choices at the new name.
- 0.5.0 has no update check, so install 0.5.1 by hand; later versions can update
  themselves.

## New and changed

- **Check for updates:** a toolbar button beside Options and About, About's Check for
  updates and an optional check at startup (Options › General › Updates, on by default)
  look for a newer release here. Download and install verifies the signed checksums,
  installs on Restart now and restores the previous version if the new one fails to start.
- **Compare Directories** follows Open Salamander's rules (size, time with tolerance and
  daylight-saving shifts, attributes, content, subfolders, ignore masks), selects
  differing folders in both panels, shows "Comparing … with …" with Cancel (Escape,
  Alt+C), reports below the active panel and marks matching (=), differing (≠) and
  one-sided (+) folders in the inline trees. It no longer hangs with subfolders.
- **HTML viewer:** Back, Forward and Reload (Alt+Left/Right, F5, Ctrl+R, mouse buttons);
  pages run their JavaScript offline in a sandbox with no network; stylesheets, fonts and
  images above the page's folder load (generated documentation and saved pages render
  correctly); the pointer becomes a hand over links.
- **Copy and Move:** copying out of an archive shows each member's path, counts first and
  gives an ETA; totals that cannot be counted exactly show "~" instead of "unknown"; the
  current file's path and bar always sit under the chart; the chart's explanation moved
  behind an "i" button.
- **Drag and drop with other applications:** a drag passes to the target application as
  soon as it leaves the window, with Explorer's data formats and drag image; drops from
  .NET applications work.
- **Custom Commands:** a Run directly command can show its output in a window (live
  output, exit code, Stop, Copy, Save, Find) or in a console window that stays open.
- **Dialogs:** the Delete confirmation asks its question first, with details below and
  long folders shortened like the path bar; Make File List is aligned and uses the
  common controls; every single-line edit has the clear button.
- **Panels and viewers:** Properties of several items opens one Windows Properties sheet;
  a Shift-click range starts at the cursor; the path bar selects the whole path when its
  editor opens; video thumbnails cycle in order every 0.8 s; the text comparison scrolls
  exactly like the text viewer.

## Fixes

- 0.5.0 refused every plugin, including the one that lists drives, when extracted into a
  folder that other accounts can change (for example under `C:\tools`), and asked users to
  run a developer script.
- A Copy from the system drive (or any folder without exact name lookups) into another
  drive failed at its first folder with "An unknown announcement requires the already
  exclusive opaque lane".
- Shift+F4 and generated files (checksums, file lists) refused to replace compressed,
  read-only or encrypted files; they now keep those attributes.
- Compare Directories with Subfolders could stop responding and left one-sided selections.

## Current limitations

- Archives are read-only, and RAR is not supported.
- On Linux, native Wayland drag and drop with other applications is new and off unless
  `MIDNIGHT_WAYLAND_DND=1`; X11 and XWayland use XDND. Files dropped from other
  applications land in a panel's current folder, never in a folder row.
- Compare Directories remembers its options only until the application closes.
- Network Neighborhood has no sign-in prompt and has not been run against a real SMB
  server.
- macOS is not implemented, and the Windows executable is unsigned.
