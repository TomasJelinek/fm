# Midnight Explorer 0.3.0 — preview

The second downloadable preview of the Rust/Slint dual-pane file manager, after
[0.1.0](0.1.0.md). It adds the internal viewers, Find, archives, Network
Neighborhood, checksums, file and folder comparison, and Copy and Move with conflict
handling, progress windows and a Jobs list.

## Downloads

- **Windows x64:** `midnight-explorer-0.3.0-x86_64-pc-windows-msvc.zip`.
  Extract the complete archive to a folder and run `me.exe`; keep the `viewers`,
  `filesystems` and `thumbnailers` folders beside it. Targets Windows 10 22H2 and
  Windows 11; development checks run on Windows 11 25H2. The executable is unsigned.
  The Microsoft Visual C++ x64 runtime is required if it is not already installed.
- **Linux x86-64:** `midnight-explorer-0.3.0-x86_64-unknown-linux-gnu.tar.gz`.
  Extract it with tar and run `./me` in an X11 or Wayland desktop. Built on Ubuntu
  24.04 (glibc 2.39 baseline). The archive's README lists the runtime packages, the
  optional desktop launcher and, for Ubuntu 23.10 and later, the HTML viewer's
  AppArmor profile. Fedora and openSUSE are compatibility targets whose native
  desktop qualification is pending.
- **`SHA256SUMS`:** verify the archives after downloading. Checksums establish
  download integrity, not code signing.

Rust and build tools are not needed to run either download. Each archive includes the
viewer, filesystem and thumbnail plugins, dependency notices and licenses, the source
revision and checksums of every module, the system requirements, the keyboard
shortcuts and the feature status.

## Available now

- **Viewers (F3):** images (PNG, JPEG, GIF, WebP, BMP, ICO, TIFF, SVG, AVIF), PDF with
  page layouts, Markdown, source code with syntax highlighting, HTML in embedded
  Chromium (offline, scripts off until allowed, always sandboxed), previews of DOCX,
  XLSX, PPTX, ODT, ODS and ODP files, video playback, and the text and hex viewer.
  Viewers search, wrap, select and copy, zoom images and PDFs, and step through the
  panel's files. Links in Markdown, HTML and Office previews can be followed; a link
  never runs a program.
- **Copy and Move** (F5, F6, the clipboard and drag and drop): one verified
  background queue that reads each copied file back and compares it by SHA-256 by
  default; Skip, a new name, folder Merge and a Replace that keeps the original
  recoverable; one Links choice; Retry, Skip or Cancel on I/O errors; a progress
  window per job with Pause, and a Jobs list.
- **Find** (Ctrl+F or Alt+F7): names by masks, regular expressions or metadata
  expressions, text, a modification period and identical files, in several folders
  and inside archives.
- **Archives:** ZIP, 7z, GZIP, XZ, Bzip2, Zstandard and TAR, also compressed, browsed
  read-only through installed archive workers. F3 views members, F5 copies them out
  through the verified queue, nested archives open up to four levels deep, and ZIP and
  7z archives ask for their password. Two archives can be open at once; opening a
  third offers to close one of them.
- **Panels:** tabs, history, Hot Paths, inline folder trees, Brief, Detailed and
  Thumbnails views (images, video frames, the first page of PDFs and archive members,
  decoded in restricted workers), the panel filter, selection by mask and folder sizes.
- **Tools:** file comparison (text, images and a streamed hex view) and directory
  comparison; Checksums (SHA-256, SHA-512, SHA-1, MD5, CRC32, and a Verify page);
  Make File List (Ctrl+M); Network Neighborhood; drive information (Ctrl+F1); Custom
  Commands, the command line and the terminal button; Attributes, times and case.
- **Options:** 26 themes, density and fonts, filename colours, keyboard shortcuts,
  file-type assignments for viewers, comparators and thumbnailers, and settings
  export and import; F1 shows the keyboard help.

## Current limitations

- Archives are read-only, and RAR is not supported. Find cannot start in a panel that
  shows an archive.
- Copy keeps the modified time only when asked to; other times, attributes, ownership,
  ACLs, extended attributes, streams and hard links are not preserved. Copy and Move
  take at most 4,096 selected items at once, and a Move at most 64.
- On Linux, Copy and a cross-volume Move write only to filesystems with `O_TMPFILE`
  (ext4, XFS, Btrfs, tmpfs); FAT, exFAT, NTFS, NFS, SMB, sshfs and GVfs destinations
  are refused. Native Wayland supports drag and drop between the panels only.
- Network Neighborhood has no sign-in prompt and has not been run against a real SMB
  server.
- Each HTML document starts its own browser, which takes about a second.
- macOS is not implemented, and the Windows executable is unsigned.
